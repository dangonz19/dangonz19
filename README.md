# Hola, soy Daniel Gonzales

Ingeniero en Informática en Santiago, Chile. Desarrollo aplicaciones web y automatizo procesos empresariales con Power Automate y Microsoft 365.

## Proyectos destacados

**[Tesis_Bomberos_Mantencion](https://github.com/dangonz19/Tesis_Bomberos_Mantencion)**
Sistema web de gestión de mantención de vehículos para un cuerpo de bomberos. Angular, Firebase (Auth, Firestore, Cloud Functions), control de acceso por roles y alertas automáticas.

**[Automatizacion-Onboarding-M365](https://github.com/dangonz19/Automatizacion-Onboarding-M365)**
Automatización del proceso de ingreso de nuevos colaboradores con Microsoft Forms, Power Automate, SharePoint y Planner.
